# ACC Portal System

A student portal prototype built with:
- Backend: Python + Flask
- Frontend: HTML + CSS
- Database: SQLite
- File upload: Valid ID (PDF/JPG/JPEG/PNG, max 5 MB)

## Features
1. Login and registration
2. Student dashboard
3. Student registration/application
4. Valid ID upload
5. Scholarship application
6. Application status
7. Admin dashboard for reviewing applications
8. SQLite database created automatically
